# vcpkg-cache v0.1.4 — shared native ccache

This source/Action release adds the reusable curl-only `setup-ccache` installer
from [PR #271](https://github.com/qigao/vcpkg-cache/pull/271). It includes the
previous native package/CI/CMake entry points and paired Lemon host tools.

## New reusable Action

```yaml
- uses: qigao/vcpkg-cache/.github/actions/setup-ccache@v0.1.4
```

The Action restores official **ccache 4.14.2** archives for Linux, macOS and
Windows x64/ARM64, verifies pinned SHA-256 digests through the shared curl
downloader, adds the executable directory to PATH, and outputs `version`.
Product repositories own compiler launchers, cache namespaces, directories,
size limits, persistence and hit statistics. Existing obfuscation launchers
must remain intact. No compiler selection or version-probe framework is added.

Downstream Actions use `@v0.1.4`; complete infrastructure checkouts use
`ref: v0.1.4`. Git registry `reference` uses the tag, but `baseline` must be the
actual full commit resolved from that tag. Earlier `v0.1.0`, `v0.1.002` and
`v0.1.003` versions stay unchanged.

## Validation

The exact installer bytes at `77b084421712ed24e1ce6f223d296efb5c3cd273` were
exercised by existing product builds and formal tests:

- [CMeta native SDK](https://github.com/qigao/cmeta/actions/runs/41559292358).
- [CMeta sanitizers](https://github.com/qigao/cmeta/actions/runs/41559292171).
- [SaltsUtils native CI](https://github.com/qigao/salts-utils/actions/runs/41558882906),
  including the shared setup-build-host Action.

Those integrations cover supported native hosts and Android cross-builds.
The source publisher checks the released installer blob matches those tested
bytes, requires all three existing qualification workflows on the exact release
PR HEAD, verifies the merged source tree, and runs the curl suite before tagging.

`Qigao.Lemon.Binary` **1.0.0**, containing the executable and paired `lempar.c`
for six build hosts. The attached Lemon nupkg, lock and SHA256SUMS are copied
from `v0.1.003` and independently hash-checked, not rebuilt or republished.

`92539e4d99c38657fa69f0bdaea73be2b35f6572cb6a9264731ae58a6da073cd`.

The semantic vcpkg cache contract remains v8. This is an infrastructure source
release; it does not publish native vcpkg ABI packages or change product
dependency graphs. Existing strict ABI restoration and product-owned build
policies continue to apply.
