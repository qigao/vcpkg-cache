# vcpkg-cache v0.1.5 — miniaudio PulseAudio initialization cleanup

Adds miniaudio **0.11.22#1** to the shared overlay and Git registry from PR #279.
Both failed-connect and failed-connection-wait paths now unref their private
PulseAudio context before freeing the mainloop. Upstream version, archive SHA512,
license and successful initialization remain unchanged.

## Validation

Exact source HEAD `d8bd0ad88943d81d1ed98c90aa0834a4294df4f7` passed all four workflows,
including [real libpulse ASan/UBSan/LSan comparison](https://github.com/qigao/vcpkg-cache/actions/runs/41761576106).
Each of three scenarios executes 32 initialization attempts:

| Scenario | Original leak | Patched |
| --- | ---: | --- |
| Invalid address | 661152 bytes / 448 allocations | Clean exit 0 |
| Absent PulseAudio socket | 662240 bytes / 448 allocations | Clean exit 0 |
| Connected Unix peer closes | 642351 bytes / 434 allocations | Clean exit 0 |

Both failure branches are asserted and the public error remains MA_NO_BACKEND (-203).
No PulseAudio disable, leak suppression, replacement provider or silent fallback.
This does not qualify successful physical-device lifecycle, iOS linking, permissions,
or the complete downstream Media SDK sanitizer/TSan graph and dependency closure.

## Versioned consumption

Reusable Actions and infrastructure checkouts may use `v0.1.5`. Git registry
`reference` uses `v0.1.5`; `baseline` must be the full commit resolved from that tag.
Products using an explicit Git registry package allowlist must include `miniaudio`
to select this recipe. Existing product locks are not changed by this release.
The overlay already includes miniaudio for consumers of the shared setup Action.

Contract v8, native ccache setup and existing tool versions remain unchanged.
The Lemon 1.0.0 nupkg, lock and SHA256SUMS are reused byte-for-byte from v0.1.003,
with verified hashes. No native ABI package is rebuilt or republished.
All earlier release tags remain unchanged.
