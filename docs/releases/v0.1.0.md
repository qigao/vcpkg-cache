# vcpkg-cache v0.1.0 — versioned shared infrastructure

This is the first versioned source distribution of the qigao shared **vcpkg
infrastructure and reusable GitHub Actions**. It is distinct from any vcpkg
port version, product SDK, or NuGet binary cache ABI.

## Contents
- Git registry + pinned Microsoft vcpkg executable/scripts and shared overlays,
  including GmSSL 3.2.0#17 imported as `GmSSL::GmSSL`.
- Versioned reusable actions `setup-vcpkg-cache`,
  `setup-vcpkg-curl-cache`, `setup-llvm-native`,
  `setup-llvm-mingw`, `setup-re2c-tools` and related setup actions.
- Linux/macOS native Clang; Windows llvm-mingw/UCRT. No new MSVC/GCC
  primary build requirement, installer/consumer/probe CI or product releases.

## Required downstream version reference
```yaml
- uses: qigao/vcpkg-cache/.github/actions/setup-vcpkg-cache@v0.1.0
  with:
    mode: read
```

Every external `qigao/vcpkg-cache/.github/actions/*` invocation must use
`@v0.1.0` rather than `@master` or arbitrary SHA. Reusable workflow
`actions/checkout` of the cache repository must use `ref: v0.1.0`.
For product-owned vcpkg manifests, the Git Registry configuration uses:

```json
{
  "kind": "git",
  "repository": "https://github.com/qigao/vcpkg-cache",
  "reference": "v0.1.0",
  "baseline": "<full commit SHA of the v0.1.0 tag>",
  "packages": ["aklomp-base64", "c-ares", "zstd", "gmssl"]
}
```

**The baseline is NOT a tag string.** vcpkg requires a real 40-character
Git commit SHA containing `versions/baseline.json`. Resolve the actual
release tag commit, then write that full SHA; keep `reference` versioned.
Do not check in a placeholder or use a guessed Git object.

## Known independent cache and runtime gates

The release is an infrastructure **source snapshot, not a statement that
all immutable native NuGet packages or downstream CTests are available**.

- ARM64 Linux `miniaudio_arm64-linux` exact remote ABI is not yet qualified;
  protected publication and independent clean-L2 restore tracked in
  [Issue #266](https://github.com/qigao/vcpkg-cache/issues/266).
- Generic post-GmSSL-merge Warm Cache CI had macOS pkgconf ranlib and
  Android libusb cross-linker RED. Unmerged
  [PR #265](https://github.com/qigao/vcpkg-cache/pull/265) tracks source
  fixes and exact curl-only ABI parity. Do not claim its changes are included
  in `v0.1.0` unless the tag actually contains those commits.
- Downstream SaltsCore source migration passed its own post-merge
  [LLVM 10/10 matrix](https://github.com/qigao/salts-core/actions/runs/41336559955).
  This does not replace the binary-cache readback checks.

No binary-cache bypass, NuGet/Mono fallback, or product release is granted
by this infrastructure version tag. Keep existing package publication
permissions, ABI verification and exact-CI gates.
