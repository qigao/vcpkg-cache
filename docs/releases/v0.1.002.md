# vcpkg-cache v0.1.002 — shared downloads for CI and CMake

This source/Action release adds one curl-only restore path for downstream
native SDK packages and host tools. It includes the no-Mono transport migration
and [PR #272](https://github.com/qigao/vcpkg-cache/pull/272).

## Downloads and downstream entry points

- `scripts/restore-native-dependency.py`: exact GitHub Packages nupkgs and
  public GitHub ZIP/tar.xz tool archives, mandatory archive SHA-256, safe
  extraction, explicit payload/required-file selection, and normalized paths.
- `resolve --version latest`: explicitly select a stable SDK/tool NuGet package
  and save its exact version and downloaded SHA-256 in a JSON lock. Normal
  builds restore that lock; configure does not silently advance versions.
  The generated digest locks the selected bytes, not an independent signature.
- `.github/actions/setup-native-dependency`: the same CLI for CI, including
  `lock-file`, receipt/root/hash outputs and optional environment/PATH exports.
- `cmake/QigaoNativeDependency.cmake`: include from a product or run with
  `cmake -P`. Supports explicit lock updates, locked restores and matching local
  installation reuse without credentials/network on repeated configure.
- Python 3.12+ including the modern Python 3.15 Windows-path validation API.

## Required downstream version reference

```yaml
- uses: qigao/vcpkg-cache/.github/actions/setup-native-dependency@v0.1.002
  with:
    lock-file: cmake/native-sdk.lock.json
    destination: ${{ runner.temp }}/native-sdk
    payload: sdk/linux-x64 # Product selects its actual host/target layout.
    env-prefix: NATIVE_SDK
```

Also select `@v0.1.002` for `setup-vcpkg-curl-cache`, `setup-re2c-tools` and
compiler setup actions. For a full source checkout use `ref: v0.1.002`; keep the
sibling Python helpers with the CMake module.
See [complete CI/CMake usage](../restore-native-dependency.md).

The Git registry `reference` is `v0.1.002`. Its `baseline` must be the real
40-character Git commit resolved from the same tag, not the tag name or a
placeholder. Obtain it with `git rev-parse 'v0.1.002^{commit}'` in a checkout that
has fetched the release tag.

## Migration and independent versions

The legacy Mono/NuGet setup action is removed. Switch to
`setup-vcpkg-curl-cache@v0.1.002`; native downloads use curl. Windows uses the
pinned llvm-mingw/UCRT compiler, Linux/macOS the runner's native Clang.
For normal product builds select `restore-packages: "false"`; strict binary-only
restoration uses `"true"` and requires every exact ABI archive.

Infrastructure source versions, SDK/tool package versions and vcpkg ABI hashes
are separate identities. This release does not publish native ABI packages,
change product dependency graphs, or certify missing package/runtime gates.
The semantic cache contract remains v8; its content revision is calculated
from the released infrastructure. Existing `v0.1.0` and package bytes stay
unchanged. The default re2c package lock remains 4.6.7 with SHA-256
`fe3c64ef3c25a28a9e5143bf2e85e3a7f25691f9bf47bec490f3e6be8e461305`.

## Validation

The release publisher verifies that the exact PR #272 HEAD has passed both
existing curl and cache-contract workflows and that the merged source tree
matches it. Qualification covers six real-package hosts: Ubuntu 22.04/24.04,
macOS Intel/ARM64 and Windows x64/ARM64. Each resolves a lock through CMake,
restores through the Action and CMake, repeats CMake without credentials, and
runs the restored re2c binary. The local curl suite has 99 tests (98 passed,
one existing platform skip); the publisher runs that same suite before tagging.
